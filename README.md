# KokoLog

<strong>KokoLog（ココログ）</strong> は、心身・仕事・タスクをひとつにまとめて記録・整理する、ブラウザ完結型のWebアプリです。



> 心身・仕事・タスクを、ひとつの場所に。



タスクを管理するだけではなく、

* 今日やること

* 業務の進捗

* 精神状態・エネルギー・ストレス

* 睡眠時間

* 頭の中にある「言いたいこと」

* それらを簡潔に整理した要点

をひとつの画面で扱えることを目的としています。

## 1. アプリ名
### KokoLog / ココログ

<strong>KokoLog</strong> は、

* Koko（ここ） — 今の自分、今の状態

* Log（ログ） — 記録する

を組み合わせた名前です。

仕事だけでも、健康管理だけでもなく、<strong>「今の自分」を記録する場所</strong>というコンセプトを表しています。

## 2. コンセプト

KokoLogは、一般的なタスク管理アプリよりも「自分の状態」を重視します。

``` 
            ┌──────────────┐
             │    KokoLog   │
             └──────┬───────┘
                    │
        ┌───────────┼───────────┐
        │           │           │
        ▼           ▼           ▼
     タスク       業務進捗      心身状態
        │           │           │
        └───────────┼───────────┘
                    │
                    ▼
              言いたいこと
                    │
                    ▼
                要点整理

```



「何をするか」だけではなく、

> <strong>今、自分はどういう状態なのか？</strong>

も一緒に記録することで、無理をしすぎず仕事や生活を整理できるようにします。

## 3. 主な機能
### <strong>📋 タスクリスト</strong>

タスクを登録し、進捗を管理できます。

* タスク名

* 優先度

* カテゴリ

* 進捗率

* 完了状態

に対応しています。

優先度は以下の3段階です。

* 高優先

* 中優先

* 低優先

進捗は <strong>0% ～ 100%</strong> の範囲で調整できます。

### <strong>📈 業務進捗</strong>

仕事をプロジェクト単位で管理できます。

例えば、

```
メイン業務     65%
サブ業務       40%
自己管理       70%
```


のように、業務全体の進み具合を視覚的に確認できます。

### <strong>🫶 心身・精神状態</strong>

その日の状態を記録できます。

<strong>精神状態</strong>

5段階で記録します。

```
😣 かなりつらい
😟 少しつらい
😐 普通
🙂 良い
😄 とても良い
```

<strong>エネルギー</strong>

<strong>1 ～ 10</strong>

<strong>ストレス</strong>

<strong>1 ～ 10</strong>

<strong>睡眠時間</strong>

時間単位で記録できます。

<strong>ひとこと</strong>

自由記述で、その日の状態を残せます。

## 4. コンディション表示

記録された状態から、現在のコンディションを簡易的に表示します。

```
休息を優先
少し注意
比較的安定
```


これは医療的な診断を行うものではありません。

あくまで、

> 「今日は少し負荷を下げたほうがよさそう」

と自分で気づくための簡易的なセルフチェック機能です。

## 5. 💬 言いたいことを簡略化

KokoLogの特徴的な機能のひとつです。

頭の中にあることを、そのまま文章で入力できます。

例えば、

```
最近ちょっと仕事が多くて疲れている。
A案件は今週中に終わらせたい。
B案件は急ぎなのか分からない。
今日は少し休みたい。
```


入力すると、簡易的なルールベース処理によって、

```
【現状】 最近ちょっと仕事が多くて疲れている。

【したいこと】 A案件は今週中に終わらせたい。今日は少し休みたい。

【気になっていること】 B案件は急ぎなのか分からない。
```


のように整理します。

AI APIを必要とせず、ブラウザ内のJavaScriptで動作する設計です。

## 6. クイック操作

以下の操作を用意しています。

### <strong>🌿 休憩</strong>

エネルギーを少し上げ、ストレスを少し下げます。

また、

```
意識的に休憩する。
```


というメモを残します。

### <strong>🎯 集中</strong>

未完了タスクから、まず集中するタスクを提示します。

### <strong>📤 JSON</strong>

現在のデータをJSONファイルとしてエクスポートできます。

### <strong>🗑 リセット</strong>

保存されているアプリデータを初期状態に戻します。

## 9. データ保存

KokoLogでは、主な保存先としてブラウザの <strong>LocalStorage</strong> を利用します。

```
lifeWork.thought

```

## 10. LocalStorage

タスク、業務、健康状態、入力した文章などをブラウザに保存します。

そのため、基本的な利用ではサーバーやデータベースを必要としません。

### メリット

* サーバー不要

* ログイン不要

* オフライン環境でも利用しやすい

* 個人用ツールとして導入しやすい

* データを外部サービスへ送信しない構成にできる

注意点

LocalStorageはブラウザに依存するため、

* ブラウザのデータ削除

* サイトデータの削除

* 別ブラウザへの移行

などによってデータが失われる可能性があります。

重要なデータはJSONエクスポートでバックアップしてください。

## 11. sql.js

KokoLogでは <strong>sql.js</strong> も利用します。

sql.jsによって、ブラウザ上でSQLiteデータベースを扱えます。

概念的には、

```
LocalStorage
│
│ 正本として保存
▼
KokoLog
│
▼
sql.js
│
▼
ブラウザ内SQLite
```


という構成です。

現在はLocalStorageをメインの永続保存先とし、sql.jsをブラウザ内データベースとして併用しています。

将来的には、履歴分析や検索などにSQLiteをより積極的に利用できます。

## 21. セキュリティ・プライバシー

KokoLogは個人の状態や仕事に関する情報を扱うため、データの取り扱いには注意してください。

現在の基本構成では、ユーザーが入力したデータをアプリ独自の外部サーバーへ送信する処理は実装していません。

ただし、利用しているCDNやブラウザ環境など、アプリ本体以外の通信については別途考慮する必要があります。

また、以下のような情報は入力しないことを推奨します。

* パスワード

* クレジットカード情報

* 他人の個人情報

* 機密性の高い認証情報

* 医療機関の診療情報など、特に慎重な管理が必要な情報

## 22. 設計思想

KokoLogでは、タスクを「全部終わらせる」ことだけを目的にしません。

例えば、

```
タスクが多い
↓
仕事が進まない
↓
ストレスが上がる
↓
エネルギーが下がる
↓
さらに仕事が進まない
```


という状態を可視化し、

```
タスク
＋
業務進捗
＋
心身状態
＋
頭の中の整理
```


を一緒に確認できるようにします。

## 26. KokoLogの目標

KokoLogが目指すのは、単なるタスク管理ではありません。

> 「今日は何をする？」

> 「仕事はどこまで進んでいる？」

> 「今、自分はどんな状態？」

> 「頭の中で何を考えている？」

> 「結局、何を伝えたい？」

これらをひとつの場所で整理できることを目指します。

### KokoLog

> 心身・仕事・タスクを、ひとつのログに。

```
KokoLog
├── 📋 Task
├── 📈 Work
├── 🫶 Health
├── 💬 Thought
└── ✨ Summary
```


自分の「ここ」を記録し、次の一歩を見つけるための小さなWebアプリです。
